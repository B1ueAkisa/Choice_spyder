# Choice_spyder

本项目是一个无需登陆即可抓取东方财富Choice金融数据终端内部数据的爬虫工具（不含机构付费下载的深度数据）。东方财富Choice是一款专业的金融数据服务提供商，本工具旨在帮助用户高效获取其海量数据资源。

通过本爬虫，您可以获取包括但不限于以下类型的金融数据：
*   **债券信息**：例如债券基本信息、发行信息、债券行情等。
*   **公司财务**：上市公司的财务报表、财务指标等。
*   **新闻资讯**：相关的财经新闻、公司公告等。
*   **舆情数据**：例如与特定平台或公司相关的网络舆情、讨论热度等。

这些数据可以为您的投资决策、市场分析、学术研究等提供有价值的参考。

## 用法

本项目主要通过以下几个Python脚本进行操作和配置：

*   `CH抓取.py`: 这是项目的主程序脚本。运行此脚本以启动整个数据抓取流程。
*   `CH抓取保存设定.py`: 此脚本定义了数据的处理方式、保存逻辑以及下载任务的调度。
*   `CH抓取源定义.py`: 这个文件至关重要，它包含了东方财富Choice数据源的定义和相关的API接口信息。用户主要通过修改此文件来调整抓取的数据范围或特定的API参数。
*   `CH抓取配置.py`: 此脚本用于配置项目的基础设置，最核心的是指定抓取数据的目标存储文件夹路径。

简而言之，进行数据抓取前的关键步骤是：
1.  **配置数据源**：根据您的需求修改 `CH抓取源定义.py` 文件，以确定您希望抓取哪些具体的数据。
2.  **设定存储路径**：修改 `CH抓取配置.py` 文件，设置好抓取数据后保存结果的文件夹位置。
3.  **启动抓取**：运行 `CH抓取.py` 脚本开始数据抓取。

## 项目结构

本项目的核心文件及目录结构如下：

*   `CH抓取.py`: 主运行文件，负责启动和执行整个数据抓取任务。
*   `CH抓取保存设定.py`: 包含了数据保存逻辑、文件下载管理以及任务调度等相关设置。
*   `CH抓取源定义.py`: 定义了从东方财富Choice金融数据终端获取数据的具体来源、API接口及参数。
*   `CH抓取配置.py`: 项目的配置文件，最主要的配置项是设定抓取数据的本地存储路径。
*   `其他需求/`: 此目录包含一些额外的脚本和工具，这些工具可能用于特定的数据预处理、分析或测试。例如：
    *   `choice研报解包.ipynb`: 一个Jupyter Notebook文件，可能用于解析和处理从Choice下载的研究报告。
    *   `网页需求.py`: 另一个Python脚本，可能包含了针对特定网页数据抓取或处理的需求。
    这些可以视为项目相关的辅助性或实验性代码。
*   `__pycache__/`: 这是Python解释器自动生成的目录，用于存放编译后的模块字节码文件（通常是`.pyc`文件）。这些文件可以提高后续模块加载的速度。此目录通常不需要用户进行直接交互或修改。

## 依赖环境

本项目主要依赖以下Python库：

*   `requests`: 用于发送HTTP请求，与网络服务进行交互。
*   `pandas`: 提供了强大的数据结构和数据分析工具，常用于处理表格数据。
*   `tqdm`: 一个快速、可扩展的Python进度条库，用于在循环和长时间运行的任务中显示进度。
*   `urllib3`: 一个强大的HTTP客户端，具有线程安全连接池、文件上传等功能。

项目所需的依赖库已在 `requirements.txt` 文件中列出。可以通过以下命令安装：
```bash
pip install -r requirements.txt
```

## 如何运行

确保已安装所有依赖库后，可以通过以下命令运行爬虫：
```bash
python CH抓取.py
```

### 定时自动运行

脚本 `CH抓取.py` 中包含了定时任务（cron job）的设置示例，可以将爬虫配置为定期自动运行。具体配置请参考该文件中的注释。

以下是一个cron任务示例，用于每周日凌晨00:01执行脚本并将日志输出到 `CH抓取.log` 文件：
```cron
# crontab -e
# 每周更新
1 0 * * 0   /home/tongjisem/anaconda3/envs/mzb/bin/python /home/tongjisem/Mzb/IFCH解包综合/5-CH解包/Choice_spyder/CH抓取.py >  /home/tongjisem/Mzb/IFCH解包综合/5-CH解包/Choice_spyder/CH抓取.log &
```
**注意**: 上述cron命令中的Python解释器路径 (`/home/tongjisem/anaconda3/envs/mzb/bin/python`) 和脚本路径 (`/home/tongjisem/Mzb/IFCH解包综合/5-CH解包/Choice_spyder/CH抓取.py`) 需要根据您的实际环境进行修改。 `nohup` 命令也可以用于在后台运行脚本，并将输出重定向到日志文件，如脚本中注释所示。

## 常见问题及解决

如果在运行过程中遇到问题，请首先查看项目根目录下的 `CH抓取.log` 文件（如果按照cronjob或nohup方式运行并配置了日志输出），其中可能记录了详细的错误信息。

常见问题可能包括：
*   **网络连接问题**：确保您的设备网络连接正常，并且可以访问东方财富Choice的相关服务。
*   **数据源API变动**：金融数据提供商的API接口可能会发生变更。如果遇到先前正常的抓取突然失败，可能需要检查并更新 `CH抓取源定义.py` 中的API端点或参数。
*   **配置错误**：请仔细检查 `CH抓取源定义.py`（数据源相关配置）和 `CH抓取配置.py`（主要是存储路径配置）中的设置是否正确无误。
*   **依赖库问题**：确保所有必要的Python库都已正确安装，并且版本兼容。可以尝试重新运行 `pip install -r requirements.txt`。
*   **文件路径问题**：当使用cron等方式自动执行时，请确保脚本中使用的所有相对路径和绝对路径都是正确的，并且执行用户具有相应的读写权限。

如果日志文件没有提供足够的信息，或者问题依然存在，建议尝试以下步骤：
1.  手动运行 `CH抓取.py` 脚本，观察控制台输出的实时错误信息。
2.  针对特定的错误信息，在网络上搜索解决方案或查阅相关库的文档。
3.  如果怀疑是数据源变动，可以尝试少量抓取一些简单的数据，以验证核心功能是否正常。

## 文件下载与数据结构说明

### 使用scp进行文件下载

以下示例命令用于通过 `scp` (secure copy) 从远程服务器下载本爬虫抓取的数据到您的本地计算机。请根据您实际的服务器地址、文件路径以及本地目标路径进行相应修改。

```bash
scp -r root@10.80.130.52:/home/tongjisem/Mzb/CH爬虫数据/平台/平台舆情  F:/Linux文件
scp -r root@10.80.130.52:/home/tongjisem/Mzb/IF爬虫数据/平台/单平台舆情  F:/Linux文件
```

**命令解释:**
*   `scp -r`: `scp` 是用于安全复制文件的命令，`-r` 参数表示递归复制整个目录。
*   `root@10.80.130.52`: 这是远程服务器的登录用户名和IP地址。`10.80.130.52` 是一个示例IP地址，请替换为您的服务器实际IP。`root` 是示例用户名。
*   `/home/tongjisem/Mzb/CH爬虫数据/平台/平台舆情` 和 `/home/tongjisem/Mzb/IF爬虫数据/平台/单平台舆情`: 这些是数据在远程服务器上存储的示例源路径。具体路径取决于您在服务器上如何组织和存储爬虫抓取的数据。例如，这里分别指向了"CH爬虫数据"和"IF爬虫数据"下的特定"平台舆情"数据。
*   `F:/Linux文件`: 这是本地计算机上用于保存下载文件的目标路径示例。

**密码提示:**
执行 `scp` 命令后，系统通常会提示您输入服务器用户的密码。
```
密码直接输完按回车
```
