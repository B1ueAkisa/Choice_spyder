# Choice_spyder


无需登陆，抓取Choice内部数据（不含机构下载数据）

## 用法

只要 修改  *CH抓取源定义.py* 就好啦！
*CH抓取源定义.py* 是 存储路径设置
抓取在 **CH抓取保存设定.py 或 CH抓取.py**中运行


## 错误问题

1. 等待秒数最好不低于0.2，不然很容易被封IP
2. 输错了cookies会导致一天的429状态码，第二天再用吧。
